# Прах забытого бога

**2D Action RPG с видом сверху в жанре тёмного фэнтези.**

## Текущая версия

Прототип **0.2**. Игра реализована в одном HTML-файле с Canvas, CSS и JavaScript — без установки дополнительных библиотек.

## Что уже реализовано

- Исследование мира с видом сверху и мини-карта.
- Пять типов противников, включая босса.
- Ближняя атака, рывок и магическое умение.
- Экипировка: оружие, броня и реликвии.
- Добыча, зелья, сундуки и осколки.
- Развитие персонажа и навыки.
- Сюжет первой главы, NPC Эйра и три древние печати.
- Автоматическое сохранение прогресса в браузере.

## Как запустить

Открой файл [index.html](./index.html) в современном браузере. На компьютере доступны клавиатурное управление и кнопки на экране; на телефоне — сенсорный джойстик и экранные кнопки.

## Управление

- WASD или стрелки — движение.
- Пробел — атака.
- Shift — рывок.
- Экранные кнопки — атака, рывок, умение и взаимодействие.
