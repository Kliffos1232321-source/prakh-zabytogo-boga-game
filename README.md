# Прах забытого бога

> Атмосферная игра в жанре тёмного фэнтези. Проект находится на ранней стадии разработки.

## О проекте

**«Прах забытого бога»** — рабочее название игрового проекта о мире, пережившем исчезновение древнего божества. Его наследие продолжает влиять на судьбы людей, а прошлое постепенно проступает сквозь руины, легенды и забытые тайны.

Это предварительное описание концепции. Подробности сюжета, игровые механики и особенности мира будут добавлены по мере развития проекта.
